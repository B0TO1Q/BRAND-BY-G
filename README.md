# Branded by G — portfolio

Portfolio site for Branded by G: websites for local businesses, by George Blanchard Jr. (Plantsville, CT).

Features the Hafele Landscaping build and the Dani Hamm spec concept, plus process and pricing.

## Files

- `index.html`: the whole page (HTML, CSS, no build step)
- `img/v2/`: full-page and phone screenshots of the featured sites (re-shoot when those sites change)

## Go live

Settings → Pages → Deploy from branch → `main` / root.
