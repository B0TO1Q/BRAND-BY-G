# Brand by G — portfolio

Portfolio site for Brand by G: websites for local businesses, by George Blanchard Jr. (Plantsville, CT).

Features the Hafele Landscaping build and the Dani Hamm spec concept, plus process and pricing.

## Files

- `index.html` Home · `work.html` Work (one section per project with a live preview of the real site; the dealership tools use screenshots) · `pricing.html` · `about.html` · `faq.html` — plain HTML/CSS, no build step; header, styles and contact section are repeated on each page
- `img/v3/`: screenshots of each featured page — `d-` desktop full page, `m-` phone full page, `t-` tile, also the preview poster while a live site loads (the live previews update themselves; only the tool screenshots and posters need re-shooting)

## Go live

Settings → Pages → Deploy from branch → `main` / root.
